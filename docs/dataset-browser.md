# Dataset browser

Datasets appear inside their groups. Click a group row to fold or unfold it; its count is the number of datasets that pass the current filters. Turn off **Tree** for one flat list that sorts across all groups and names each dataset's group; the choice is remembered. Rows drop the words every sibling shares, so `4MHz, YSL AOTF 50 µW` and `5MHz, YSL AOTF 50 µW` show as `4MHz` and `5MHz`. A name stays whole when shortening would leave it blank or the same as another row. The flat list shows the shared words above it, a group row's tooltip lists them, and each dataset's tooltip has its full name. Only the display changes: stored names, search and export are unaffected.

Click column headers to sort ascending or descending; in the tree, rows sort within their group. Right-click a header to show or hide columns. Favorite and Acquisition date are hidden by default; Acquisition date appears by itself when some dataset has a known date. Acquisition date uses the earliest valid parsed instrument datetime; missing dates display Unknown. Numeric timestamp streams with an unspecified epoch are not interpreted. Filesystem creation and modification times are never substituted. Dates retain the instrument’s unspecified timezone. Channels counts scan signal channels, or stored columns for tabular datasets.

Select rows, then use Organize → Toggle favorite ★, Edit tags, or Edit comments. Tags are comma separated, and ★ in the list marks a favorite; editing multiple selected rows replaces their tags or comments. These annotations can be changed on raw data without modifying observations, acquisition metadata, or revisions. Editable copies inherit independent annotations. Annotations persist in JSON and HDF5 projects, with empty defaults for older projects. Edit → Undo / Redo restores annotation changes during the session.

The search box matches names, groups, sources, tags, comments and instrument metadata. `field = value` matches a metadata or title field exactly, and `tag:name` keeps datasets with a tag containing name (`tag:favorite` or `tag:★` for favorites). The **Tags** button lists every tag with its count, favorites first; tick tags to show datasets carrying any of them. Group and raw/derived filters are folded under **Filters**, which shows how many are active. Search, tags and the folded filters combine with AND, and searching unfolds the groups holding matches. Filters and sorting do not alter grouping, dataset order in the project, or plot visibility. Hidden rows lose selection. Clearing filters does not reselect them.

Highlighted rows control inspection and organization; the first-column checkboxes control plotted datasets. Opening a project resets filters and restores its active dataset by identity, even when the browser is sorted.
